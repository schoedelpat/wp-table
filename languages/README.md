# WP Table - Translation Template

This directory will contain language files for translating the WP Table plugin.

## How to Create Translations

1. Use a tool like Poedit to create `.po` files from the plugin's text strings
2. The text domain is `wp-table`
3. All translatable strings use the `__()`, `_e()`, and `_x()` functions
4. Save translation files as `wp-table-{locale}.po` and `wp-table-{locale}.mo`

## Examples

- `wp-table-es_ES.po/mo` - Spanish (Spain)
- `wp-table-fr_FR.po/mo` - French (France)
- `wp-table-de_DE.po/mo` - German (Germany)

## Contributing Translations

If you'd like to contribute translations, please submit them through the plugin's GitHub repository.
